# 真选择实验（2026-11-25）

不碰游戏代码：把 `js/` 拷到 `/tmp/moexp/js`，按 `defend_实验改动.diff` 给 `defend.js` 加三个开关，再把 `exp.js` 放进 `/tmp/moexp` 跑。
- `global.RANGE_K`：射程倍数（0.6 = 缩到六成）
- `global.CLEAR`：一波要等场上的龙全碎或全进门才结束（倒计时一到不再出新龙，但已经在路上的不自动碎）
- `global.LEAK`：倒计时一到、场上每节扣城墙多少血（第一版试过，不公平：刚出口的龙也算，已弃用）

用法：`node exp.js 关序号 世界 选法 局数 龙血倍数`
- 世界：now（现在）/ range（只缩射程）/ clear（只改波末）/ fix（两样都改）
- 选法：spots（开点位的顺序：按设计 / 随机 / 倒序）、assign（哪件放哪个空位）、combine（合哪件：第一个 / 随机 / 最后一个）、card（挑卡：第 1 张 / 随机）

机器人：每秒合一次、能修点位就修、同名就叠。结果见 `结果_20261125/`，结论写在 `墨守_检验报告_1.0_20261125.md` 第八节第 4 条。
