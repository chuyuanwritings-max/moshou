## 怎么玩
- 按住屏幕左右拖，黄铜机关龙自己往上冲。
- 吃**铜零件**（写几就加几节）；撞**城砖**会停下来啃，啃一口掉一节，砖上的数字到 0 就碎。龙被啃光就输。
- **木栅栏**挡住横移；**弩塔**（砖上架连弩、插红旗）朝你射箭，射中掉一节，拆掉崩出零件。
- 道具：铜甲（撞砖不掉节）、火药桶（炸掉屏幕上的砖）、磁石（零件自己飞来）。
- 最后一道**城门**写着数字，攒够节数一头撞开就过关。三个地方各两关：边城、古墓、兵马俑地宫。
- 结算：铜钱升「起步 +1 节」。

## 文件
- `js/config.js` 数值；`js/sim.js` 规则 + 机器人；`js/draw.js` 画法（风格库 祝有好收获）；`js/main.js` 手指、特效、结算。
- `node tools/build-preview.js` 打包成 `preview.html` / `index.html`。
- `node test/sim-balance.js` 不开画面跑几百局量数；`node test/robot.js` 浏览器里走一遍（截图在 `test/shots/`）。
