## 怎么玩（局内一个字的说明都没有）

- 一打开就开打。第一关有一只手指左右滑的动画，滑过一次就消失。
- **一根手指按住左右滑** = 阿铸在城墙上左右走，蒸汽连弩自己往上射。
- 公输班的机关长龙沿着弯路爬向城门，每节写着血。打碎**朱漆机关匣**那一节 → 时间停下，三张卡选一张：多发、连射、重弩、穿透、弹墙、炸开、冻住、会心。
- 打碎最前面那节 = 整条龙往回退一节；打掉中间的，后半截会追上来补位。
- **龙越短越急**：剩最后几节时爬得最快。尾巴最硬，最后一节是铁色的「攻城槌」，三倍血。
- 龙头离城门只剩一节 → 时间放慢，弹出「拉总闸」（假广告）：城墙上一排炮齐射，龙退 10 节。每局一次。
- 龙头进了城门就输。失败页写「还差几节」，快打完时写「差一点！」，一个大按钮「再守一次」。

## 局外（最小一套）

| | 怎么来 | 有什么用 |
| --- | --- | --- |
| 金币 | 每打碎一节 1 个，赢了另给；输了也给 | 结算页「升级弩机」：每级伤害 +12% |
| 铜雀 | 第一次过第 1 关 | 多发出得更勤，每级多两箭 |
| 木犬 | 第一次过第 2 关 | 弹墙出得更勤，弹过墙的箭伤害翻倍 |
| 蒸汽龟 | 第一次过第 4 关 | 一开局就会炸开，炸得更大 |

结算页可以换带谁上城墙。带哪只，三选一时它偏爱的那张卡更常出，卡角上有它的小像。广告（假按钮）只有两处：拉总闸、结算金币翻倍，每局最多 3 次。

## 自测结果（2026-11-19）

### 三个数（`node test/measure.js`：100 个「普通」玩家各从第 1 关连玩 15 局，会升弩机、会解锁伙伴）

| 数 | 结果 | 目标 |
| --- | --- | --- |
| 一局平均几秒 | **134 秒**（第 1 关 53 秒，第 2 关起 140 秒，最长 217 秒；含每次三选一约 1.5 秒） | 120–180 秒 |
| 死到再开局几秒 | **1.03 秒**，只点一下（`test/robot.js` 用真按钮量；机器人一能点就点，真人再加反应时间） | ≤3 秒 |
| 输的局里「差一点」占多少 | **69%**（输的那一刻龙只剩不到两成或不到 5 节） | ≥30% |

另外：第 1 局过第 1 关 100%；第 2 局（第一次打第 2 关）普通玩家赢 41%、聪明的赢 60%；15 局内 93% 的人打到第 6 关。发呆乱晃的机器人第 1 关也能过（97%），之后几乎全输：说明走位真的有用。

「差一点」的算法改过：交接单写的是「离终点 ≤1 格」，但这游戏每次输都是龙到了城门，那样算永远是 100%。

## 文件

| 文件 | 管什么 |
|---|---|
| `js/config.js` | 所有数值：关卡、技能、伙伴、弩机、广告；调手感只改这里 |
| `js/sim.js` | 一局的规则（不画图）：龙怎么爬、箭怎么飞、三选一、拉总闸、输赢 |

| `js/draw.js` | 画面，全用代码画 8 比特（阿铸、龙、机关匣、攻城槌、三只伙伴、八个技能图标、城墙） |
| `js/main.js` | 画面切换、手指、局外、特效、声音 |
| `js/sfx.js` | 声音（代码合成） |
| `js/platform.js` | 唯一的平台层：微信 / 浏览器 |
| `tools/build-preview.js` | 打包成 `preview.html` / `index.html` |
| `test/wx-smoke.js` | 假装微信环境跑一遍 |
| `test/robot.js` | 手机大小的浏览器里用鼠标当手指走完整流程 |

| `test/measure.js` | 模拟玩家连玩 15 局，量三个数 |
